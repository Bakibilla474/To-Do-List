# To-Do List

A small browser-based task list built with semantic HTML, CSS, and vanilla JavaScript.

## Features

- Add a task with the form or the keyboard
- Mark tasks complete with a native checkbox
- Remove tasks with an accessible button
- Treat task text as text, so user-entered markup is not executed
- Use the layout on narrow screens and with keyboard navigation

## Run locally

Open `index.html` in a modern browser. The project has no build step or external runtime dependencies.

## Scope

Tasks live in the current page only and are cleared when the page reloads. This project does not use an account, server, or browser storage.
